**Why this release:** the Helldivers 2 fix changes hands. Release `-2` carried a workaround of this repository's own for the game's `STATUS_INVALID_HANDLE` crash, which kept a woken thread waiting until its waker was out of `LeaveCriticalSection()`. This release replaces it with Valve's own fix for the same crash, Paul Gofman's "ntdll: Ignore semaphore errors in RtlpUnWaitCriticalSection()" from Proton Experimental's bleeding-edge branch: `LeaveCriticalSection()` no longer raises when releasing a critical section's semaphore fails, which is the step that turned the game's late leave into a crash. It is seven lines, on for every game, changes no timing and covers the cases the workaround missed; `WINE_CS_WAKE_GUARD` goes away with the workaround ([write-up](https://github.com/jegglest/proton-je/blob/proton-je-11.0-20261014-3/docs-je/helldivers2-renderer-race.md)). Tested with a new probe, `docs-je/repro/cs_leave_bad_semaphore.c`; the in-game result is not in yet. Same base and same other patches as `-2`.
