**Why this release:** `proton-je-11.0-20261001-1` and `-2` abort any game once it has about 3300 handles open at once and waits on one of the higher ones. Patch 5 made the in-process sync cache entry 20 bytes, the cache mapped its 64K blocks at the entries' exact size, 65520 bytes, and Wine's `anon_mmap_alloc()` asserts that its size is a multiple of the page size: the game disappears or freezes, and the only trace is one line in Steam's console log, ``virtual.c:408: anon_mmap_alloc: Assertion `!(size & host_page_mask)' failed.`` Found with Foundry during an autosave. The cache now maps whole 64K blocks ([details](https://github.com/jegglest/proton-je/blob/proton-je-11.0-20261001-3/docs-je/patches/ntsync-mutex-in-use-after-close.md#the-change)); nothing else changed since `-2`. Please replace `-1` and `-2` with this build.
