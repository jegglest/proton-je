**Why this release:** Proton Experimental 20261027b has two of the commits this branch carried in its own Wine, so the rebase onto it dropped them: Wine's `81e52628`, the same change as patch 1 (a use-after-return in the `RtlWaitOnAddress()` wakers, Wine bug 60397, point 1), which Valve took as `b2a60dcd145`, and Paul Gofman's fix for the Helldivers 2 `STATUS_INVALID_HANDLE` crash, Valve's `d5c4b850198`, which `-3` and `-4` carried as the last commit of their Wine. This build has both, from Valve's Wine. The patches for upstream are now patches 2 to 6, unchanged except that patch 2's context has Wine's form of patch 1's change.

**FSR 4 on RDNA4 is no longer carried:** the 26 commits of Etaash Mathamsetty's FSR 4 work from Proton-EM and the `proton` script's handling of the FSR 4 DLL are gone, so that this branch carries only the patches for upstream; the `proton` script is Valve's. A build from source has no FSR 4 DLL, so with this build games that offer FSR 3.1 stay on FSR 3.1 on every GPU, where Steam's own Proton Experimental upgrades them on RDNA3 cards. Proton-EM and Proton-GE carry the FSR 4 work.
