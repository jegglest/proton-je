**Why this release:** two new patches, 7 and 8, on the same base as `-1` (patches 2 to 6 unchanged). A thread killed with `TerminateThread()` now gets its TEB, its stack and its kernel stack freed when the next thread starts or exits, as Windows frees a killed thread's stack; Wine used to keep them for as long as the process ran. Helldivers 2's anti-tamper code creates two suspended threads and kills them every 0.4 seconds, so under earlier builds the game grew by about 34 GiB of address space and 360 MiB of resident memory an hour ([write-up](https://github.com/jegglest/proton-je/blob/proton-je-11.0-20261027b-2/docs-je/killed-thread-stacks.md)). Patch 8 is the conformance test in `kernel32:thread`, which fails on `-1` and passes with the patch and on Windows 11.
